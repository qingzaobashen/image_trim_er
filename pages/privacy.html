隐私政策

最后更新日期：2025年5月28日

隐私保护承诺

抠白底图工具高度重视用户的隐私保护。我们承诺：您在网站上传和处理的每一张图片都不会被发送到任何远程服务器。所有图像处理操作（包括抠图、选区调整、边缘平滑等）均在您的浏览器本地通过 JavaScript 和 Canvas API 完成。这意味着您的图片数据永远不会离开您的设备，充分保障了您的数据安全与隐私。

本隐私政策详细说明了我们收集哪些信息、如何使用这些信息以及与谁共享。请仔细阅读本政策，以了解我们对您个人信息的处理方式。

我们收集的信息

1. 您主动提供的信息

当您通过联系我们页面提交反馈或建议时，我们可能会收集您提供的姓名、电子邮件地址和消息内容。这些信息仅用于回复您的询问，不会用于其他目的。

2. 自动收集的信息

为了改善网站性能和用户体验，我们可能会通过 Google Analytics 等工具自动收集以下非个人身份信息：

  • 浏览器类型和版本（如 Chrome 120、Firefox 121）
  • 操作系统信息（如 Windows 11、macOS Sonoma）
  • 访问的页面和停留时间
  • 引荐来源（您从哪个网站访问本站）
  • 大致的地理位置（仅到城市级别）

请注意，这些信息均为匿名化的统计数据，无法用于识别您的个人身份。

3. 我们不收集的信息

我们明确不收集以下信息：

  • 您上传的任何图片文件内容
  • 您处理的图片的像素数据
  • 您的 IP 地址（除非在 DDoS 防护等安全场景下临时记录）
  • 您的真实姓名、电话号码或地址（除非您主动在联系表单中提供）

Cookie 政策

抠白底图工具使用 Cookie 和类似技术来提供、保护和改进我们的服务。以下是关于我们如何使用 Cookie 的详细说明：

1. 必要型 Cookie

这些 Cookie 是网站正常运行所必需的，无法在我们的系统中关闭。它们通常仅根据您的操作（如设置隐私偏好、登录或填写表单）进行设置。您可以设置浏览器阻止这些 Cookie，但网站的某些功能可能无法正常工作。

2. 分析型 Cookie

我们使用 Google Analytics 等第三方分析工具来帮助我们了解访问者如何与网站互动。这些 Cookie 收集的信息是匿名的，包括访问者数量、流量来源和访问的页面。这有助于我们评估和改进网站内容。

3. 广告型 Cookie（未来可能使用）

如果您在本网站看到广告（如通过 Google AdSense 投放），广告合作伙伴可能会使用 Cookie 来展示与您相关的广告。这些 Cookie 允许广告商识别您的设备并了解您的浏览习惯，但不会识别您的个人身份。

4. 如何管理 Cookie

大多数浏览器允许您控制 Cookie 的设置。您可以在浏览器设置中：

  • 删除现有的 Cookie
  • 阻止浏览器接受新的 Cookie
  • 在收到新 Cookie 时通知您
  • 禁用第三方 Cookie

请注意，禁用 Cookie 可能会影响您在本网站的使用体验。

信息使用方式

我们使用收集到的信息用于以下目的：

  • 提供和改进服务：确保网站正常运行，优化页面加载速度和用户界面
  • 分析使用趋势：了解用户如何使用我们的工具，以便开发更实用的功能
  • 回复用户咨询：通过您提供的联系方式回复您的问题和建议
  • 安全防护：检测和防止恶意攻击、垃圾信息和欺诈行为
  • 法律合规：在必要情况下遵守适用的法律法规

第三方数据共享

我们非常重视您的数据安全，仅在以下有限情况下与第三方共享信息：

1. 分析服务提供商

我们使用 Google Analytics 来分析网站流量和用户行为。Google Analytics 收集的数据是匿名的，不会包含您的个人身份信息。

2. 广告服务（如适用）

如果本网站展示广告（例如通过 Google AdSense），广告网络可能会使用 Cookie 和类似技术来展示相关广告。

3. 法律要求

在法律要求或政府请求的情况下，我们可能会披露您的信息。此外，如果我们认为披露对于保护我们的权利、财产或安全，或保护我们的用户或公众的安全是必要的，我们也可能进行披露。

4. 我们不会出售您的数据

我们不会出售、出租或以其他方式交易您的个人信息给任何第三方用于营销目的。

数据安全

我们采取了多种技术和组织措施来保护您的信息安全：

  • 纯本地处理：所有图像处理在浏览器本地完成，图片数据不上传服务器
  • HTTPS 加密：网站通过 HTTPS 协议传输数据，防止中间人攻击
  • CSP 策略：实施内容安全策略，限制脚本和资源的加载来源
  • 定期审查：定期审查和更新安全措施，以应对新的安全威胁

尽管我们努力保护您的信息，但请注意，没有任何一种互联网传输或电子存储方法是 100% 安全的。我们鼓励您在使用互联网时保持警惕。

您的权利

根据适用的数据保护法律，您对您的个人信息享有以下权利：

  • 访问权：您有权要求我们提供所持有的关于您的个人信息的副本
  • 更正权：您有权要求我们更正不准确的个人信息
  • 删除权：您有权要求我们在某些情况下删除您的个人信息
  • 限制处理权：您有权要求我们在某些情况下限制对您个人信息的处理
  • 数据可携带权：您有权以结构化、通用的格式获取您的个人信息
  • 反对权：您有权反对我们基于合法利益处理您的个人信息

如果您希望行使上述任何权利，请通过我们的联系页面与我们联系。我们将在合理的时间内回复您的请求。

政策更新

我们可能会不时更新本隐私政策。当我们进行重大更改时，我们会通过在本页面发布更新后的政策并更新"最后更新日期"来通知您。我们鼓励您定期查看本页面以了解最新的隐私保护措施。

如果您对本隐私政策有任何疑问或担忧，请随时通过联系我们页面与我们取得联系。
